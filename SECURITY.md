# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x (latest) | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them via [GitHub private vulnerability reporting](https://github.com/schlebek/registration-blocker/security/advisories/new)
or by email: **stanislaw.chlebek@gmail.com**

Include:
- Plugin version
- WordPress and PHP versions
- Description of the vulnerability
- Steps to reproduce (if applicable)

You can expect an acknowledgement within 5 business days and a fix or mitigation plan within 14 days of a confirmed report.
